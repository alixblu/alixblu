\subsection{{DEVOPS / CLOUD ENGINEER --- Course Project \hfill Mar. 2026 --- Apr. 2026}}
\subtext{\href{https://github.com/akira3175/BuocChanSoiDa.git}{Food Street Commentary WebApp} \hfill \href{https://foodstreet.alixblu.site}{ https://foodstreet.alixblu.site}}
\subtext{\\[-0.5em] \hfill \href{https://github.com/akira3175/BuocChanSoiDa.git}{ https://github.com/akira3175/BuocChanSoiDa.git}}

\vspace{0.4em}
\noindent Web application that automatically plays location-based audio narration in multiple languages for nearby food street points of interest, with integrated user and admin management system.\par
\noindent \textbf{Tech Stack:} Python, Django, AWS EC2, AWS ECR, AWS RDS, Docker.\par
\vspace{-0.7em}
\begin{zitemize}

    \item Designed and implemented CI/CD pipelines to automate build, testing, and deployment workflows.
    \item Deployed and managed cloud infrastructure using AWS EC2, ECR, Docker, and RDS.
    \item Handled project migration from local environment to cloud production deployment.
    \item Configured public domain access, networking, and service integration.
    \item Contributed to POI API integration and application logic flow.
\end{zitemize}

\subsection{{TEAM LEAD / BACKEND DEVELOPER --- Course Project \hfill Oct. 2025 --- Dec. 2025}}
\subtext{\href{https://github.com/alixblu/review-platform.git}{Beauty Product Review Platform} \hfill \href{https://github.com/alixblu/review-platform.git}{ https://github.com/alixblu/review-platform.git}}
\vspace{0.7em}
\noindent Comprehensive beauty product review platform built with microservices architecture, featuring user authentication, product management, social interactions, and AI-powered chatbot assistance.\par
\noindent \textbf{Tech Stack:} Java, Spring Boot, Spring Cloud Gateway, PostgreSQL, Neo4j, Docker, AWS Cognito, AWS S3, AWS Bedrock.\par
\vspace{-0.7em}
\begin{zitemize}
    
    \item Led backend system architecture design and task decomposition for a modular, service-oriented application.
    \item Designed and implemented relational and graph database schemas using PostgreSQL and Neo4j.
    \item Developed RESTful backend services for authentication, product management, user reviews, and social interactions.
    \item Integrated AWS Cognito for authentication, S3 for media storage, and built a RAG chatbot powered by AWS Bedrock.
    \item Containerized services with Docker to standardize local development.
\end{zitemize}
