\subtext{\textbf{DevOps/Cloud Engineer} -- Personal Project \hfill \href{https://github.com/alixblu/devops-lab.git}{github.com/alixblu/devops-lab}}

\vspace{0.7em}
\noindent Cloud-native deployment pipeline for a backend service on Amazon ECS with automated delivery, multi-AZ availability, application load balancing, observability, and secrets management.\par
\noindent \textbf{Tech Stack:} AWS CodePipeline, Amazon ECS with Fargate, Amazon VPC, Application Load Balancer, CloudWatch, Secrets Manager.\par
\vspace{-0.7em}
\begin{zitemize}

    \item Designed Amazon VPC networking with public and private subnets across multiple Availability Zones, routing, and security group controls; ECS tasks run in private subnets with the Application Load Balancer as the public entry point.

    \item Configured an Application Load Balancer with ECS target groups, health checks, and traffic routing to distribute requests across backend tasks.

    \item Automated the full deployment workflow with AWS CodePipeline and deployed the service on Amazon ECS with Fargate across multiple Availability Zones for high availability.

    \item Implemented observability with Amazon CloudWatch Logs, metrics, and alarms; secured database credentials and API keys in AWS Secrets Manager and injected them into ECS tasks at runtime.
\end{zitemize}

\noindent \textbf{Tech Stack:} AWS Bedrock, Amazon S3, AWS Lambda, Amazon API Gateway, AWS CloudFormation.\par

\vspace{-0.7em}

\begin{zitemize}

    \item Provisioned and managed the full AWS cloud infrastructure using CloudFormation, ensuring repeatable and consistent resource deployment.

    \item Built an AI-powered RAG chatbot using Amazon Bedrock Knowledge Bases, with Amazon S3 as the document data source and a Bedrock foundation model for response generation.

    \item Developed the serverless chatbot response workflow with AWS Lambda, integrating the Bedrock Knowledge Bases and foundation model.
